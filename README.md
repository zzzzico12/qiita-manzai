# Manzai Script Generator

This project includes two main scripts:

1. **manzai.py**: This script generates the manzai script and saves it into a file named `manzai_script.txt`.
2. **generate.py**: This script reads the `manzai_script.txt` file and converts the script into an MP3 audio file named `manzai_full.mp3`.

## Usage
- Run `manzai.py` to create the script.
- Run `generate.py` to generate the audio file from the created script.
