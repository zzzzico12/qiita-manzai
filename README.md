# Project Overview
This project uses Claude AI agents to generate manzai scripts and AWS Polly for voice synthesis.

# Agent Composition
- **Boke Agent**: Utilizes Claude Sonnet.
- **Tsukkomi Agent**: Utilizes Claude Haiku.
- **Orchestrator Agent**: Coordinates the overall process.
